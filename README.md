# Vesper Brewing landing page

An interactive launch page for the six Vesper Brewing releases, built for Advanced Branding Assignment 11.

Open `index.html` in a browser. Choose a release, drag or swipe the can to rotate it, or use the arrow buttons. Select **Enlarge the label** to inspect the flat artwork at full size.

- `index.html` and `styles.css` define the page.
- `collection.js` holds the release copy and selection controls.
- `can-viewer.js` projects the wrap around the rotating can.
- `can-texture.js` contains the six lossless browser textures rendered directly from the Assignment 10 vector proofs.
